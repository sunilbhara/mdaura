# FAQ

### Is MDAura free?

Yes. MDAura is free and open source under the MIT licence. There is no account and nothing to pay.

### Can I edit documents in MDAura?

No. MDAura is a reader. Edit in your usual editor and open the file again.

### My images do not show

Relative image paths, like `images/chart.png`, need the image files too. Open the folder with **Folder** on the home page. See [Opening files](/docs/opening-files#open-a-folder-with-images).

### A diagram shows an error instead of a picture

Mermaid could not read the diagram source. The message under the heading tells you which line it stopped at. Check the [Mermaid syntax reference](https://mermaid.js.org/intro/) for that diagram type.

### Does MDAura work offline?

Once the page has loaded, opening and reading files works without a connection.

### Which browsers are supported?

Current versions of Chrome, Edge, Firefox and Safari. Opening a folder needs a browser that supports folder selection, which all of these do.

### Is there a size limit?

50 MB per file.

### Where can I see what changed?

In the [release notes](/releases).

### Can I contribute?

Yes. The source code is on GitHub. Bug reports and pull requests are welcome.
