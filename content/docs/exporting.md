# Exporting

Select **Export** in the reader's toolbar. All exports are created in your browser.

| Format | Best for | Includes diagrams |
|---|---|---|
| Word (`.docx`) | Editing, review with tracked changes | Yes, as images |
| PDF | Sending a fixed copy, printing | Yes |
| Markdown (`.md`) | Getting the original file back | As source |
| PowerPoint (`.pptx`) | Marp decks only | Not yet |

## Word

The Word file keeps headings, lists, tables, code, links, quotes and images. Each diagram is drawn on a white background and added as a picture. The document title appears in the page header, and the footer shows page numbers.

Large documents with many diagrams can take a few seconds. The menu shows **Preparing…** while it works.

## PDF

**PDF** opens your browser's print dialog. Choose **Save as PDF** as the destination. The toolbar, outline and buttons are hidden in the printout, and code blocks, tables and diagrams are kept on one page where they fit.

> For a cleaner PDF, switch to the light theme before printing.

## Diagram images

To get a single diagram, open it full screen and select **SVG** or **PNG**. See [Diagrams](/docs/diagrams#full-screen-viewer).
