# Keyboard shortcuts

Press <kbd>?</kbd> in the reader to see this list at any time.

## Reader

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Search the document |
| <kbd>[</kbd> | Show or hide the outline |
| <kbd>.</kbd> | Focus mode |
| <kbd>+</kbd> | Larger text |
| <kbd>-</kbd> | Smaller text |
| <kbd>?</kbd> | Keyboard shortcuts |

On a Mac, use <kbd>⌘</kbd> in place of <kbd>Ctrl</kbd>.

## Full-screen diagram

| Keys | Action |
|---|---|
| <kbd>F</kbd> | Fit to screen |
| <kbd>0</kbd> | Actual size |
| <kbd>+</kbd> / <kbd>-</kbd> | Zoom in or out |
| Arrow keys | Pan. Hold <kbd>Shift</kbd> to move further. |
| <kbd>R</kbd> | Replay the animation |
| <kbd>S</kbd> | Show or hide the source |
| <kbd>Esc</kbd> | Close |

## Presentation

| Keys | Action |
|---|---|
| <kbd>→</kbd> <kbd>Space</kbd> | Next slide |
| <kbd>←</kbd> | Previous slide |
| <kbd>Esc</kbd> | Leave the deck |
